# 區塊 worker 規則

你負責影片的一個區塊：把原始字幕整理成台灣用語的繁體中文字幕、逐字稿文章和區塊筆記。主 agent 只會看到你的回報，所以檔案要一次寫對。

## 輸入

prompt 會給你 skill 資料夾、區塊編號 `NN` 和 work 資料夾。全部檔案都在 `<work>/chunks/` 和 `<work>/`：

| 檔案 | 用途 |
|---|---|
| `chunks/chunk_NN.srt` | 這一塊的原始字幕。從頭讀到尾。 |
| `chunks/chunk_NN.context.txt` | 上一塊最後幾句，只用來理解上文，內容不放進輸出。第一塊沒有這個檔。 |
| `meta.json` | 影片標題、說明、語言。用來判斷主題和名詞。 |
| `terms.md` | 名詞對照表。表裡有的名詞一律用「統一寫法」。 |

## 輸出

在 `<work>/chunks/` 寫出三個檔案。

### 1. `chunk_NN.zh-TW.srt`：繁中字幕

- **時間戳是鎖定的**：每一句輸出字幕對應一句原始字幕，序號行和時間戳行整行照抄，順序不變。一句字幕太長也不拆，太短也不併。
- 文字寫成台灣用語的繁體中文：
  - 原文是中文：轉成繁體，再校對。
  - 原文是其他語言：翻成繁體中文，一句字幕翻一句。一個句子跨好幾句字幕時，照語序把譯文分配到這幾句。
- 校對：依上下文、影片標題和 `terms.md`，修正聽錯的同音字和專有名詞。無法確定時，寫最可能的寫法並在後面加 `(?)`，列進回報。
- 標點：句中用全形標點（，、：「」），句尾不加句號，保留問號和驚嘆號。
- 刪除：只刪 whisper 幻覺，也就是跟上下文無關的句子，例如靜音處冒出來的「請訂閱頻道」「字幕由 Amara.org 社群提供」，或同一句不斷重複。整句刪掉（序號、時間戳、文字一起刪），最多刪這一塊的 5%，刪了幾句寫進回報。

格式：

```srt
12
00:03:15,240 --> 00:03:18,900
所以考古學家認為，這批人來自中國南方

13
00:03:18,900 --> 00:03:21,500
這個說法到今天還有爭議
```

### 2. `chunk_NN.article.md`：逐字稿文章

- 把這一塊改寫成通順的段落：論點、例子、數字、人名、引用全部保留；口頭禪、重複、口誤刪掉。
- 每段 3–6 句，段首標 `[HH:MM:SS]`，取該段第一句字幕的開始時間（時:分:秒）。
- 話題轉換時可以加 `###` 小標題。
- 文章會和前後區塊直接接起來，所以直接寫內容，開頭不寫「這一段」「接下來」這類銜接語，也不寫結語。
- 只寫影片說到的內容；背景補充放進名詞解釋。

### 3. `chunk_NN.notes.md`：區塊筆記

照這個格式寫，四個 `###` 標題都要有：

```markdown
## chunk_NN（HH:MM:SS–HH:MM:SS）

### 摘要

2–4 句，說明這一塊講了什麼、得出什麼結論。

### 主題段落

- [HH:MM:SS] 主題名稱：一句說明

### 重點

- 一個完整的觀點或事實（[HH:MM:SS]）

### 名詞

- 統一寫法（原文）：1–2 句解釋（[HH:MM:SS]）
```

「名詞」收人名、地名、組織、作品名、專有名詞和術語；這一塊沒有就寫 `- 無`。原文和統一寫法相同時，括號寫原文語言的寫法或省略。

## 台灣用語

用台灣讀者習慣的詞，例如：

| 不用 | 用 |
|---|---|
| 视频、視頻 | 影片 |
| 软件、軟件 | 軟體 |
| 程序（電腦） | 程式 |
| 网络、網絡 | 網路 |
| 信息 | 資訊、訊息 |
| 质量 | 品質 |
| 默认 | 預設 |
| 服务器 | 伺服器 |
| 屏幕 | 螢幕 |
| 激光 | 雷射 |
| 土豆（馬鈴薯） | 馬鈴薯 |
| 打印 | 列印 |

## 自我檢查

三個檔寫完後執行：

```bash
node "<skill 資料夾>/scripts/vtn.mjs" check --work "<work>" --id NN
```

結果是 `FAIL` 就照訊息修正、重寫檔案，再跑一次，直到 `OK` 或 `WARN`。`WARN` 裡的簡體字要改成繁體。

## 回報格式

只回這幾行，不貼字幕或文章內容：

```text
chunk_NN：完成（check：OK／WARN：原因）
刪除字幕：N 句（原因；沒有就寫 0）
不確定：寫法(?) — 可能是 A 或 B；…（沒有就寫「無」）
名詞：統一寫法 ← 原文；…（terms.md 沒有的新名詞；沒有就寫「無」）
```
